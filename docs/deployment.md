# Deployment

- Host: Linux with Python 3.11 and the fingerprint-chromium 150 Linux build. On Debian 12 install `xvfb`, `openbox`, `x11vnc`, `novnc`, `websockify`, `sqlite3`, `fonts-crosextra-carlito`, `fonts-liberation`, `python3-venv`, `libnspr4`, `libnss3`, `libatk1.0-0`, `libatk-bridge2.0-0`, `libxkbcommon0`, `libasound2`, `libgbm1`, `libxcomposite1`, and `libatspi2.0-0`.
- Display: install the [Xvfb](../deploy/tokenwatch-xvfb.service), [Openbox](../deploy/tokenwatch-openbox.service), [x11vnc](../deploy/tokenwatch-x11vnc.service), and [noVNC](../deploy/tokenwatch-novnc.service) units. Start them in that order, then start [tokenwatch](../deploy/tokenwatch.service). They share the `tokenwatch` user's virtual display `:77`.
- Layout: code in `/opt/tokenwatch`, virtualenv in `/opt/tokenwatch/venv`, private config in `/etc/tokenwatch` (mode 600, owned by the `tokenwatch` user).
- Config files: `config.local.toml` from [server/config.example.toml](../server/config.example.toml) and `browser.local.toml` from [the browser example](../server/tokenwatch/browser/config.example.toml). Production values live only in `/etc/tokenwatch/*.local.toml`. The browser config requires `request_timeout` and `close_timeout`; see [architecture](architecture.md#components) for their meaning. `signing_key` in `config.local.toml` is the Arkham client key; never put its value in the repository.
- Set optional screenshot settings only in `/etc/tokenwatch/browser.local.toml`, with the screenshot directory outside the repository and private to the service.
- Service: [deploy/tokenwatch.service](../deploy/tokenwatch.service) runs one uvicorn worker on loopback; its listen port is set in the unit. A systemd drop-in can override `ExecStart` to use another port when required by the reverse proxy. Expose it to the client only through an HTTPS reverse proxy or an SSH tunnel. An HTTPS reverse proxy must forward all paths, including the `/login-view/<ticket>/websockify` WebSocket, with upgrade headers and a read timeout long enough for an idle noVNC session; a 60-second timeout can drop an idle login WebSocket.
- Browser persona: `persona = "windows"` runs with `--disable-spoofing=canvas` by default (`disable_spoofing` in the browser config), because canvas spoofing breaks the Turnstile click described in [arkham-upstream.md](arkham-upstream.md). Known defect: with canvas spoofing off, the canvas hash does not depend on `fingerprint_seed` and equals the hash of a browser without persona on the same host (software rendering), so accounts on one host share it. Canvas spoofing is also reported broken on Linux in 148 and 150 ([#94](https://github.com/adryfish/fingerprint-chromium/issues/94), [#96](https://github.com/adryfish/fingerprint-chromium/issues/96)). Not addressed.
- Persona environment (host side, outside the repository), for the user that runs the browser (`HOME=/opt/tokenwatch`):
  - Screen work area: `~/.config/openbox/rc.xml` copied from `/etc/xdg/openbox/rc.xml` with `<margins><bottom>40</bottom></margins>`, then `kill -USR2` the Openbox process. The page then sees `screen.availHeight` 40 px below `screen.height`.
  - Fonts: install `fonts-crosextra-carlito`. fingerprint-chromium passes names on its built-in basic-font list (Arial, Calibri, Segoe UI, Microsoft Sans Serif, Times New Roman, Courier New, and others) to fontconfig unchanged, so an alias in `~/.config/fontconfig/fonts.conf` makes them measurable: Calibri resolves to Carlito, and Segoe UI and Microsoft Sans Serif are aliased to Liberation Sans. Names outside that list (Cambria, Consolas, Verdana, Georgia) are replaced or hidden by the seed and cannot be controlled by installing fonts.
  - Not controllable by any launch option: `navigator.deviceMemory` reports 16, `speechSynthesis` has no voices, and `navigator.gpu` exists but `requestAdapter()` returns null.
- Remote login: x11vnc listens only on `127.0.0.1:5900` using `/opt/tokenwatch/.vnc/passwd`, created with `x11vnc -storepasswd` and owned by `tokenwatch` with mode 600. Classic VNC authentication uses only the first eight bytes of the password. Websockify serves `/usr/share/novnc` only on `127.0.0.1:6080`; set `novnc_url = "http://127.0.0.1:6080"` and `vnc_password` to the same password in the private server config. The interactive browser opens on the service's `DISPLAY`. Login URLs use a one-time ticket; see [login session](architecture.md#login-session) for the client flow. The [manual CLI helper](../server/tokenwatch/browser/README.md) remains available when the service is stopped.
