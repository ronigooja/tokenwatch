# Deployment

- Host: Linux with Python 3.11, Xvfb, Openbox, and the fingerprint-chromium 150 Linux build. The service uses the virtual display `DISPLAY=:77` that must already run as the `tokenwatch` user with Openbox, so a human can reach the same desktop through x11vnc and noVNC.
- Layout: code in `/opt/tokenwatch`, virtualenv in `/opt/tokenwatch/venv`, private config in `/etc/tokenwatch` (mode 600, owned by the `tokenwatch` user).
- Config files: `config.local.toml` from [server/config.example.toml](../server/config.example.toml) and `browser.local.toml` from [the browser example](../server/tokenwatch/browser/config.example.toml). Both stay out of the repository.
- Service: [deploy/tokenwatch.service](../deploy/tokenwatch.service) runs one uvicorn worker on `127.0.0.1:8000`. Expose it to the client only through an HTTPS reverse proxy or an SSH tunnel.
- Browser persona: `persona = "windows"` runs with `--disable-spoofing=canvas` by default (`disable_spoofing` in the browser config), because canvas spoofing breaks the Turnstile click described in [arkham-upstream.md](arkham-upstream.md). Known defect: with canvas spoofing off, the canvas hash does not depend on `fingerprint_seed` and equals the hash of a browser without persona on the same host (software rendering), so accounts on one host share it. Canvas spoofing is also reported broken on Linux in 148 and 150 ([#94](https://github.com/adryfish/fingerprint-chromium/issues/94), [#96](https://github.com/adryfish/fingerprint-chromium/issues/96)). Not addressed.
- Persona environment (host side, outside the repository), for the user that runs the browser (`HOME=/opt/tokenwatch`):
  - Screen work area: `~/.config/openbox/rc.xml` copied from `/etc/xdg/openbox/rc.xml` with `<margins><bottom>40</bottom></margins>`, then `kill -USR2` the Openbox process. The page then sees `screen.availHeight` 40 px below `screen.height`.
  - Fonts: install `fonts-crosextra-carlito`. fingerprint-chromium passes names on its built-in basic-font list (Arial, Calibri, Segoe UI, Microsoft Sans Serif, Times New Roman, Courier New, and others) to fontconfig unchanged, so an alias in `~/.config/fontconfig/fonts.conf` makes them measurable: Calibri resolves to Carlito, and Segoe UI and Microsoft Sans Serif are aliased to Liberation Sans. Names outside that list (Cambria, Consolas, Verdana, Georgia) are replaced or hidden by the seed and cannot be controlled by installing fonts.
  - Not controllable by any launch option: `navigator.deviceMemory` reports 16, `speechSynthesis` has no voices, and `navigator.gpu` exists but `requestAdapter()` returns null.
- Remote login: run x11vnc and noVNC/websockify bound to `127.0.0.1` only; set `novnc_url` to the noVNC HTTP endpoint reachable by the service. The interactive browser opens on the service's `DISPLAY`. Configure x11vnc authentication and, if needed, set `vnc_password` in the private server config; the password is included in the authenticated login URL and must not be logged. Access the server over HTTPS. See [login session](architecture.md#login-session) for the client flow. The [manual CLI helper](../server/tokenwatch/browser/README.md) remains available when the service is stopped.
